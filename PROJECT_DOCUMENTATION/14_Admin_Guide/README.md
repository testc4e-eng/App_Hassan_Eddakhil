# Admin Guide

Ce guide décrit l’espace administrateur et les fonctions de gouvernance.

## Objectifs administratifs

- gérer les utilisateurs
- surveiller les accès
- protéger les routes sensibles
- conserver un environnement propre et lisible

## Fonctions disponibles

| Fonction | Description |
|---|---|
| Lister les utilisateurs | visualiser tous les comptes |
| Créer un utilisateur | ajouter un nouveau compte |
| Modifier un utilisateur | corriger le nom, l’email ou le rôle |
| Activer / désactiver | contrôler l’accès à la plateforme |
| Réinitialiser le mot de passe | fournir un nouveau mot de passe temporaire |
| Supprimer | retirer un compte selon la politique interne |

## Bonnes pratiques

- vérifier le rôle avant toute action de modification
- conserver les identifiants d’administration hors du code
- suivre les derniers accès pour détecter les comptes inactifs
- utiliser le changement de mot de passe après toute réinitialisation

## Navigation

L’administrateur dispose du même environnement visuel que le reste du projet, avec un accès direct à:

- Dashboard
- Suivi Climat
- Suivi Hydrologique
- Suivi érosion
- Analyse Spatiale
- Rapport & Export
- Gestion utilisateurs
