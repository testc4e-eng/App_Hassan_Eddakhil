# User Guide

Ce guide décrit l’usage standard de la plateforme côté utilisateur métier.

## Parcours de base

1. ouvrir `/login`
2. saisir email et mot de passe
3. accéder à l’espace autorisé selon le rôle
4. choisir le module métier
5. filtrer station, scénario, variable et période
6. lire le graphe, les statistiques et le tableau
7. exporter si nécessaire

## Comprendre les écrans

### Dashboard

Le dashboard rassemble les modules de suivi et les vues analytiques.

### Analyse spatiale

Le module spatial permet de comparer:

- la base de données brute
- le projet Hassan Addakhil

### Scan de données

Le scan sert à repérer:

- les tables présentes
- les périodes disponibles
- les anomalies potentielles

## Conseils de lecture

- vérifier la station active avant d’interpréter un graphe
- vérifier la plage de dates disponible
- regarder les statistiques avant de conclure
- utiliser l’export pour un traitement externe

## Actions utiles

- changer de langue FR/EN
- changer de module
- ouvrir une modal d’agrandissement
- télécharger un export CSV
