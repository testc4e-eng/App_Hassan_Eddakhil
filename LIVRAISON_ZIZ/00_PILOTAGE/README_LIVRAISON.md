# LIVRAISON_ZIZ

Le dossier `LIVRAISON_ZIZ` centralise les audits, rapports, scripts, configurations, validations et éléments préparatoires de la livraison destinée à Ziz.

Il s'agit d'un espace de préparation de la release, séparé des sources applicatives du projet.

Le dossier `10_PACKAGE_FINAL` contiendra uniquement les éléments effectivement remis à Ziz.

Les fichiers du projet source ne doivent pas être modifiés depuis ce dossier de livraison.

Les secrets, mots de passe, tokens et autres informations sensibles ne doivent jamais être copiés dans les rapports ou documents de ce dossier.
